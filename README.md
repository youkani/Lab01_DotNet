## Главные выводы
1. .NET — это бесплатная кроссплатформенная платформа от Microsoft для создания различных приложений.
2. Git позволяет отслеживать изменения, возвращаться к предыдущим версиям проекта и синхронизировать его с удаленным репозиторием на GitHub.
3. В C# нужно явно указывать тип переменной. Это помогает избежать ошибок — компилятор проверит типы ещё до запуска программы.
4. var не делает переменную «динамической» как в Python. Тип определяется один раз при объявлении и больше не меняется.
5. В C# деление целых чисел (int / int) даёт целый результат.

## Ответы на вопросы
1. Чем Console.Write() отличается от Console.WriteLine()?
Console.Write() выводит текст без перехода на новую строку, а Console.WriteLine() выводит текст и добавляет символ перехода на новую строку в конце.
2. Что произойдёт, если попытаться присвоить переменной типа int значение 3.14?
Произойдет ошибка компиляции, потому что 3.14 это тип double, и его нельзя преобразовать в int без потери данных.
3. Почему 10 / 3 в C# даёт 3, а не 3.333...? Как получить дробный результат?
 Чтобы получить дробный результат, хотя бы одно число должно быть дробным.
4. Что означает var в C#? Чем он отличается от динамической типизации в Python?
var это автоматическое определение типа у переменной, а в Python тип переменной спокойно изменяется.
